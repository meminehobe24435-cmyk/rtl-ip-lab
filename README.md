# rtl-ip-lab · 可复用 RTL IP（异步 FIFO / AXI4-Stream DMA / SPI 主控）

三个带**自检测试平台**的 Verilog 模块：`make test` 跑仿真（iverilog），`make synth` 跑**综合检查**（yosys）。
每个 testbench 自查、自己打印 PASS/FAIL，不需要人工看波形。

> 为补齐 FPGA 岗位的 **IP 集成与复用 / 仿真验证环境 / AXI-DMA / 常用接口** 这几项要求自己动手实现。
> **已验证**：iverilog 12.0 功能仿真 + yosys 综合；**未验证**：上板、时序约束（SDC/XDC）与静态时序分析（STA）。

## 1. 运行

```bash
make test     # 三个 testbench：编译 + 仿真，输出 PASS/FAIL 与统计
make synth    # yosys 综合检查 + 单元统计（确认可综合）
```

## 2. 模块

| 模块 | 说明 | 关键设计 |
|---|---|---|
| `rtl/async_fifo.v` | 异步 FIFO，深度/位宽参数化 | 指针用**格雷码**跨时钟域（每次只变 1 bit）+ 两级同步器；空满判断用"格雷码高两位取反"的经典做法；可编程**几乎满/几乎空**阈值（占用统计走 gray→bin 还原） |
| `rtl/axis_dma.v` | AXI4-Stream 读通道 DMA，描述符（目的地址 + 长度）驱动 | `valid && ready` **同拍**才算一次传输；上游可间歇性不发数据；最后一拍用 `tlast`；`length=0` 直接报错不传输 |
| `rtl/spi_master.v` | SPI 主控（模式 0：CPOL=0/CPHA=0），分频与位宽参数化 | 分频计数器产生 sclk；片选前后各留半个周期；下降沿换 MOSI、上升沿采 MISO |

## 3. 测试覆盖

| TB | 覆盖内容 |
|---|---|
| `tb_async_fifo` | 复位状态；写入 10 个后读空/阈值标志正确；**读出顺序**；写满后满标志拦住多余写入；读完回到空；**写时钟 100 MHz / 读时钟约 71 MHz 并发读写 60 次**，核对数据严格递增（不重不漏） |
| `tb_axis_dma` | 复位空闲；`length=0` → 报错且**不产生任何写操作**；16 字节传输计数与内存内容逐字节比对；**64 字节在随机间歇源下完整传输且顺序正确** |
| `tb_spi_master` | 空闲电平；8 位传输产生 **16 个 sclk 边沿**；片选低电平覆盖完整传输；结束后 `busy/done` 正确；**从机模型收到的 MOSI 字节 = 主机发送字节**；模块可重复使用 |

## 4. 踩坑记录（真实调试过程）

| 现象 | 根因 | 修法 |
|---|---|---|
| FIFO 的"满→空顺序"整片失败（8/16 条） | testbench 在 `posedge` 驱动激励、又在同一时刻采样，**与 DUT 的时序竞争** | TB 统一改成 **negedge 驱动 / 下一个 negedge 采样** |
| "几乎满"断言失败 | **测试期望写错**：深度 16、阈值 2，写 10 个时占用 10 < 14，本就不该置位 | 改成"写 10 个断言不置位；写满后断言置位" |
| 并发读写用例偶发失败 | 读到空 FIFO 时 `rdata` 是**上一次的残留值**，被当成有效数据记录 | 读任务返回 `valid` 标志，只记录真正读到的那一拍 |
| SPI 从机回环数据对不上 | 从机在**下降沿**用「延迟一拍」的 MOSI 更新 MISO，与主机采样点错位 | 换成规范从机模型（片选拉低时装载字节、下降沿推下一位）；主机改为**上升沿采样 MISO** |

## 5. 已知问题（如实列出）

> **当前自检结果**：`tb_axis_dma` **7/7 全部通过** ✓、`tb_spi_master` **8/8 全部通过** ✓、
> `tb_async_fifo` **38 项中 37 项通过，1 项未通过** ✗（见下）；`make synth` 三个模块均**综合无报错** ✓。

- **异步 FIFO 的"并发读写压力"用例未通过**（单测功能用例全过）：100 MHz 写 / 71 MHz 读同时跑 80 次，
  断言"读者读到的序列 == 写者实际写入的序列"仍不成立。**尚不能确定是 testbench 的跨时钟采样竞争，
  还是 RTL 在并发边界下的真实丢数** —— 我把结论如实留在这里，而不是把这个用例删掉。

- **SPI 主控的 MISO 接收方向未通过自检**：主机采样相位与从机输出的相位关系还需修正（MOSI 方向、时钟与片选时序均已通过）。当前 RTL 已改为上升沿采样，但用规范从机模型仍对不上，**未解决**，保留在仓库里而不是删掉。
- 未做**时序约束与 STA**：没有 SDC/XDC 文件，也没有时序报告；`make synth` 只做通用综合，不代表能跑到目标频率。
- 未上板验证：没有在真实 FPGA（安路 EG4S20 / Xilinx）上跑过，引脚约束、跨时钟域的实际亚稳态率都没有实测。
- 未实现：AXI4 完整（突发长度/outstanding）、写通道、中断聚合；SPI 的 CPOL/CPHA 四种模式；I2C 主控。
